## 脱敏规则

为入库到公开仓库，以下内容已做不可逆替换。**列结构、描述文本、模块层级、状态枚举、冗余列分布均原样保留**，分析可用性不受影响。

| 类别 | 处理 |
|---|---|
| 测试环境明文口令（`admin <口令>`） | → `admin ********` |
| 内网 IPv4 | → `10.0.0.N`（保留不同主机的区分度） |
| 内网域名 | → `*.example.com` |
| 内部扫描任务 ID（`STG…`） | → `STG-MASKED` |
| 设备序列号 | → `SERIAL-MASKED` |
| 人员姓名（申请人/发现人/解决人/验证人等） | → `员工N`（同一人前后一致） |
| 部门与工作组路径 | → `部门N`（保留路径深度） |
| `缺陷ID` 单元格超链接（`flowInstId`） | 已清除，保留显示文本 |
| 单元格批注 | 已清除 |

未脱敏（刻意保留，因为分析需要且已公开于设计文档）：缺陷 ID、标题、描述正文、所属模块、测试模块、状态/结论枚举、严重级别、质量特性、项目编号、产品名称与版本。

## 复现脱敏

规则与脚本思路见设计文档 §附录 C；原始导出请向缺陷平台重新导出。
